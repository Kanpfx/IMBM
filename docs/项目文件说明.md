# 项目文件说明

当前项目已按运行职责做功能模块化整理，并把细分模块收进所属上层包：`agents/` 管 LLM agent 和 prompt，`game/` 管游戏观测、动作、校验、自动逻辑和建议，根目录只保留入口、配置、运行时、静态知识、文档与归档。动作校验和游戏控制逻辑保持不变；IM 的 `predicted_observation` 输出由 `-observation` 开关控制。

## 根目录

| 文件 | 作用 |
|---|---|
| `main.py` | 入口，只调用 `cli.main()`；命令 `python main.py ... -bm` 可使用。 |
| `.env` | 本地私有环境变量，保存 `IM_*` 和 `BM_*` 模型配置。 |
| `.env_template` | 环境变量模板。 |
| `README.md` | 项目说明、运行命令和结构概览。 |
| `docs/IMBM_CHANGES.md` | IMBM 相对 SunTzu 的改造说明。 |
| `requirements.txt` | Python 依赖。 |

## 活跃主链路

| 文件/目录 | 作用 |
|---|---|
| `cli.py` | 实际启动逻辑：解析参数、加载环境变量、构造 LLM client、创建 `ImBmPlayer` 并调用 `run_game()`。 |
| `player.py` | 当前 IMBM 主玩家。同步运行 IM 生成动作，异步调度 BM 生成战略指令。 |
| `agents/base.py` | Agent 基类。 |
| `agents/immediate.py` | Immediate Model：只负责 LLM 调用、response parse/refine 和 verifier 回调；`predicted_observation` 由 `-observation` 开关控制。 |
| `agents/background.py` | Background Model：只负责 LLM 调用、plan critic/refine 和结果解析。 |
| `agents/prompts/` | IM/BM prompt 字符串、规则和 prompt builder。 |
| `runtime/directive.py` | `Directive` 与 `DirectiveStore`，用于 BM 到 IM 的线程安全指令传递。 |
| `runtime/run_logger.py` | 每局 `overview.json`、`obs/`、`im/`、`bm/` 的分类日志写入。 |
| `runtime/logging.py`、`runtime/metrics.py` | 迭代指标辅助函数。 |
| `game/base_player.py` | 薄 adapter：挂接 `game/observation/`、`game/verifier/`、`game/actions/`、`knowledge/` 和基础日志能力。 |
| `game/llm_player.py` | 薄 adapter：挂接 `game/automation/` 与 `game/suggestions/`，供 IMBM 主玩家复用。 |
| `game/observation/` | 观测文本构造：整体 builder、单位/建筑、能力、地图与资源信息。 |
| `game/actions/` | 动作执行和建筑落点查找。 |
| `game/verifier/` | 动作 schema、资源/单位/target/ability 校验。 |
| `game/automation/` | 自动工人、MULE、自动反击和早期 SCV 防守。 |
| `game/suggestions/` | 全局建议与 Terran/Protoss/Zerg 种族建议。 |
| `config/` | 环境变量加载、generation config、地图/难度/种族枚举。 |
| `utils/` | LLM client、JSON/text 格式和通用辅助函数。 |

## 数据、文档和诊断

| 路径 | 作用 |
|---|---|
| `knowledge/abilities.py` | 能力表和 SC2 API 数据加载、target 类型查询、ability description 构造。 |
| `knowledge/TerranAbility.csv` | 动作能力表，供 prompt 能力描述和动作校验使用。 |
| `knowledge/data.json` | SC2 API 数据，供 ability target 类型判断使用。 |
| `docs/fig/` | README 图片和本地 HTML 架构说明。 |
| `logs/` | 运行产物：`overview.json`、`obs/`、`im/`、`bm/`、`run.log` 和 replay。 |

## `archive/`

| 路径 | 内容 |
|---|---|
| `archive/legacy_suntzu/agents/` | 旧 `ActionAgent`、`PlanAgent`、`SingleAgent`、`RagAgent` 和 prompt helper。 |
| `archive/legacy_suntzu/players/` | 旧 `MinerPlayer`、`NoPlayer` 等 baseline player。 |
| `archive/scripts/` | 旧 benchmark、数据采集、Elo、SFT、GUI、diagnostics、notebook 和日志汇总脚本。 |
| `archive/tools/` | 当前主链路未使用的 tokenizer 工具和资源。 |
| `archive/cache/` | 整理时从旧顶层目录挪入的缓存目录。 |
